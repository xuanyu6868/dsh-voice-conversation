## 结论与边界

- 本轮可确认：首句提前合成、MSE 逐块播放与正常插话路径工作；主样本首段正文→首声为约 2.0–2.3 秒。
- endpoint 是实测事件；“物理说完”仍由 endpoint-700ms 推算，不是独立声学测量。
- 长回复 10.87→6.39 秒是本次场景对比，回复长度与生成时序不同，不能据此承诺所有对话固定减少 4.48 秒。
- 本窗口只有 1 次 voice.start 和 1 次 voice.end，没有第二个通话绑定的运行证据；不能把本轮插话证据扩展成跨会话切换/隔离实机验收。既有自动测试仍保留。
- 冷启动、实际断网/合成故障、米家工具复测、设置版本号目测、扬声器/耳机差异保持未验证。
- 预取多数衔接很快，也有约 0.4–0.8 秒等待；请求数随逐句合成上升，仍可观察，不宣称插件优化空间耗尽。
