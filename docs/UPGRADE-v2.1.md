# v2.1 更新与 Harness 实机验收提示词

本版替换 v2.0 的录音/转写/确认发送流程。沿用已有云端识别与 Edge TTS 配置，不需要重装模型或改记忆系统。

## 给 DeepSeek Harness 的完整提示词

```text
请更新并实测我的语音插件，仓库：https://github.com/xuanyu6868/dsh-voice-conversation。
目标版本 package.json 与 client.js 均为 2.1.0。先读该仓库 README.md、HANDOFF.md 和本文件，确认线上实际加载的代码，不要只凭插件列表或旧日志断言已生效。

这次只处理语音：
1. 持续收音，边说边更新语音页中同一条用户气泡；最小化时语音条显示最新转写。
2. 过滤纯符号和前导多余标点，保留正常语句标点、小数及正常短回答。
3. 停顿约 0.7 秒后，最终识别成功即提交；没有确认卡片和额外 1.5 秒倒计时。键盘输入仍手动发送，语音不能读写普通聊天草稿。
4. 设置、键盘、查看历史、最小化、浏览别的页面、模型工作和朗读不停止录音。主动静音/结束、明确去另一会话开启以及设备故障恢复按定义处理。
5. 朗读时直接说话：语音起判即停播放/合成/预取，最终文本用 native steer 中断旧轮次，不另发可能迟到的 cancel。

请先检查工作树是否有我或其他代理未提交的修改，保留这些修改；以可回滚方式更新当前真正生效的插件目录，记录更新前版本和提交。不要改我的云端 API key、提供方、音色或其他插件，不要碰 OpenViking、记忆库和米家控制台。

运行 npm ci、npm run check、npm test（当前应为 70 项），核对 package.json/client.js 版本。重载 voice-conversation 一次，拿到重载之后的新日志与版本证据。只有确实需要重启应用时才安排重启，不要反复重载。

特别注意：remote.speech.transcribe 是 batch API；speech.follow 只是服务状态流。本版采用增量音频快照，并非云端原生逐字流式。请读取本机 speech catalog 和实际 ASR 配置，告诉我真实提供方/模型、是否有原生流式协议、首个文字与最终识别耗时。不要猜是 SenseVoice，不要换成浏览器语音识别，也不要用打字动画冒充真实流式。增量快照增加请求量，请据实际服务核对限流/费用。

按以下步骤配合我操作并关联同一时段日志：
A. 安静保持 30 秒：不出现纯符号用户消息、误发或新模型请求。再说“好”“不”“3.14”，验证有效短句与小数未误删。
B. 说一段 6–10 秒的话：没说完时同一气泡应有真实部分结果，不能等全句才一次出现；停顿后只提交一次，无确认卡片、无倒计时。记录 speech onset→首文字、endpoint→最终结果、send→收据时间。
C. 普通聊天输入框先写草稿不发送，进入/最小化语音并说话：普通草稿保持原样且不误发。语音页键盘输入不自动提交，同时麦克风继续工作。
D. 同一句话中打开设置、开关键盘、收起展开、查看历史与切换页面：音频仍在采集，不能出现“正在聆听”但无 PCM；如有恢复，日志和界面必须如实标记。显式静音后必须停止收音，取消静音再恢复。
E. 让助手说较长回答，分别在耳机和 Mac 扬声器环境插话“停一下，换个问题”：播放应在语音起判后停止，转写实时更新，最终只发一条 steer 新问题，旧回复不恢复朗读、不串入新问题。不以模型仍执行工具误判播放未停，明确区分阶段。
F. A/B 会话各有不同事实：普通浏览 B 时 A 通话仍属 A；在 B 明确开启则切到 B，使用 B 的历史/模型/工具权限；A 的迟到识别和收据不能写入 B。
G. 模拟识别错误/超时：未完成的部分文字不能被当成最终命令自动发出；失败文字留在气泡，麦克风继续工作；发送收据未知不可自动重试。

日志关注 mic.connected（AudioWorklet / ScriptProcessor）、mic.degraded/stalled/error、voice.input-start/endpoint/barge-in、asr.first-text/request/result/error、send.start（queue/steer）、send.accepted/error 与 ui.long-task。
如果仍全局卡十几秒，请先采集当前进程/主线程/IPC 与这些时间戳，定位后再改，不要声称自动测试已经证明现场问题消失。

输出请分三段：已由代码/自动测试验证；本机实测通过（必须有实际操作或对应新日志）；未验证/失败项。不要把尚未由我说话测试的声学效果写成通过。将结果脱敏写回此仓库；不得提交 key、录音、聊天原文或原始日志。
```

## 回滚

若出现回声自激、误发或兼容问题，先结束语音再回滚到更新前记录的插件版本；保留对应时段的本机诊断供定位。不要通过放宽会话隔离或自动重试控制指令掩盖问题。
